# نظام إدارة مستشفى لجنة زكاة ميت على التخصصي

نظام إدارة طبي شامل (عيادات، أسنان، عمليات، تحاليل، أشعة، خزينة، مرتبات) —
مبني كملف HTML واحد مستقل (Vanilla JavaScript)، بدون أي أدوات بناء (build tools)،
مع قاعدة بيانات سحابية عبر [Supabase](https://supabase.com) وتخزين محلي (IndexedDB)
يعمل حتى بدون اتصال بالإنترنت (Offline-first).

## الإصدار الحالي
v1.2.0 — راجع تعليق `APP_VERSION` أعلى ملف `index.html` لتفاصيل كل إصدار.

## الأقسام المتاحة
- يومية العيادات + ملفات مرضى العيادات
- يومية الأسنان + ملفات مرضى الأسنان
- يومية العمليات
- يومية التحاليل (بقائمة أنواع تحاليل قابلة للتخصيص من الإعدادات، مع دعم اختيار أكثر من تحليل للمريض الواحد)
- يومية الأشعة (بقائمة أنواع أشعة قابلة للتخصيص من الإعدادات، مع دعم اختيار أكثر من نوع أشعة للمريض الواحد)
- الوارد / المنصرف / دفتر الخزينة
- المرتبات والمستحقات
- التقارير (يومية / شهرية / سنوية)
- إدارة المستخدمين والصلاحيات الدقيقة لكل موظف
- سجل نشاط شامل (Audit Log)

## ⚠️ خطوات أساسية قبل أي استخدام حقيقي (مهم جدًا)

هذا المستودع **عام (Public)**. الكود يحتوي على مفتاح Supabase (`anon key`) مُضمَّن
مباشرة — وهذا آمن بشرط تفعيل **Row Level Security (RLS)** على كل جداول قاعدة
البيانات في مشروع Supabase، فالمفتاح نفسه لا يمنح أي صلاحيات فعلية بدون سياسات RLS
مناسبة.

**لكن يجب عليك فورًا عند أول تشغيل:**

1. **تغيير كلمة مرور المدير الافتراضية.** أول تسجيل دخول يكون بـ:
   - اسم المستخدم: `admin`
   - كلمة المرور: `1234`

   غيّرها فورًا من: الإعدادات ← تغيير كلمة المرور. كلمة المرور الافتراضية هذه
   مكتوبة صراحة في الكود المصدري العام، فلا تتركها كما هي.

2. **تأكد من تفعيل RLS** على كل الجداول في لوحة تحكم Supabase (Authentication →
   Policies) قبل إدخال أي بيانات حقيقية للمرضى.

3. لا ترفع أبدًا أي نسخة احتياطية (JSON) تحتوي بيانات مرضى حقيقية لهذا المستودع.

## التشغيل محليًا
النظام ملف واحد مستقل — لا يحتاج تثبيت أو بناء:
```bash
# افتح الملف مباشرة في المتصفح، أو شغّل خادم محلي بسيط:
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## الإعداد الأول (Supabase)
1. أنشئ مشروع جديد على [supabase.com](https://supabase.com).
2. نفّذ سكريبت SQL الخاص بإنشاء الجداول (راجع `sql/schema.sql` إن وُجد، أو اطلبه
   من داخل محادثة تطوير النظام).
3. من داخل النظام: الإعدادات ← الاتصال بـ Supabase ← أدخل الرابط والمفتاح.

## البنية التقنية
- HTML/CSS/JavaScript خام بدون أي إطار عمل (framework)، لضمان بساطة النشر والصيانة.
- تخزين محلي عبر IndexedDB (يعمل أوفلاين بالكامل).
- مزامنة سحابية عبر Supabase (PostgreSQL + REST) مع طابور مزامنة ومعالجة تعارضات.
- دعم كامل للغة العربية وتخطيط RTL.

## الترخيص
هذا النظام ملك خاص لمستشفى لجنة زكاة ميت على التخصصي. جميع الحقوق محفوظة.
