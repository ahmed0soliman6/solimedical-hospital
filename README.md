# SoliMedical Hospital

صفحة ويب تجريبية مستقلة لنظام إدارة المستشفى باسم **SoliMedical Hospital**. هذه النسخة تعمل محليًا ولا تحتوي على اتصال بـ Firebase أو بأي قاعدة بيانات خارجية.

## تسجيل الدخول التجريبي

| الحقل | القيمة |
|---|---|
| اسم المستخدم | `admin` |
| كلمة المرور | `55555555` |

تُستخدم بصمة PBKDF2 للتحقق من كلمة المرور، ولا تُحفظ كلمة المرور النصية داخل الكود. الجلسة المحلية تنتهي تلقائيًا بعد مدة محددة، كما توجد حماية مؤقتة بعد عدة محاولات فاشلة.

## تشغيل الصفحة

يمكن فتح `index.html` مباشرة في المتصفح، والأفضل تشغيل خادم محلي بسيط:

```bash
python3 -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000
```

أو يمكن مشاهدة النسخة المنشورة من خلال GitHub Pages إذا كان workflow الخاص بالصفحات مفعّلًا في المستودع.

## محتويات النسخة

تحتوي الصفحة على شاشة دخول عربية متجاوبة، لوحة تحكم تجريبية، مؤشرات تشغيل، وحدات المرضى والمواعيد والأطباء والتقارير والخزينة، وقائمة مواعيد تجريبية. أزرار الوحدات تعرض رسالة توضح أنها جاهزة للتفعيل في المرحلة التالية.

كل البيانات الظاهرة في لوحة التحكم ثابتة لغرض العرض فقط. لا توجد بيانات مرضى حقيقية، ولا توجد قاعدة بيانات محلية للمستشفى في هذه النسخة.

## الربط المستقبلي

عند اعتماد Firebase لاحقًا، يُفضّل إنشاء مشروع Firebase جديد خاص بـ SoliMedical، ثم إضافة طبقة تخزين منفصلة وقواعد Firestore خاصة، بدل إعادة استخدام أي إعدادات أو مشروع تابع لـ Mitali Hospital.

## ملاحظة أمنية

هذه صفحة تجريبية وليست نظام مصادقة إنتاجيًا. بيانات الدخول منشورة داخل متطلبات التجربة، ولذلك يجب تغييرها وإعادة بناء آلية المصادقة قبل استخدامها فعليًا أو إدخال أي معلومات طبية.

## صفحات الأقسام والأطباء

تتضمن النسخة الحالية صفحات تفصيلية للعيادات الخارجية، الأسنان، العمليات، التحاليل، والأشعة. من كل قسم يمكن مشاهدة بطاقات الأطباء، التخصص، الغرفة، ساعات العمل، أيام الحضور، عدد المواعيد، والجدول الأسبوعي للقسم، إضافة إلى جدول مواعيد القسم والجدول الموحد لكل المجمع.

كما توجد صفحات مستقلة للأطباء والجداول، المواعيد الموحدة، والتقارير التشغيلية التجريبية. كل هذه البيانات محلية للعرض ولا تمثل بيانات حقيقية.
